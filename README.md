# tom-portfolio

Personal portfolio for **Tomás Muñoz — AI Automation Engineer**.

Single-page site: Vite + React + TypeScript + Tailwind, dark theme.

## Develop
```bash
npm install
npm run dev
```

## Build
```bash
npm run build      # tsc + vite build → dist/
npm run preview
```

Images live in `public/img/{labraza,tio-toro,duendes}/`. Missing images fall back to a neutral placeholder (layout stays intact).
